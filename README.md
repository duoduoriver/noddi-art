# duoduohe TanStack

SaaS starter for shipping faster on Cloudflare Workers.

duoduohe TanStack is a production-ready TanStack Start template for modern SaaS
products. It includes AI, auth, payments, storage, email, newsletter, blog,
dashboard, SEO, and Cloudflare Workers deployment.

## Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Useful Commands

```bash
pnpm build
pnpm check
pnpm lint
pnpm deploy
```

## Deployment

Before deploying, update `wrangler.jsonc`, environment variables, payment
product IDs, OAuth redirects, and mail sender domains for your own Cloudflare
and provider accounts.

## Brand

The public product name is `duoduohe TanStack`. Package and Cloudflare resource
names use `duoduohe-tanstack`.
